# 문제은행 전수 검수 작업대장

이 문서는 대화 컨텍스트가 압축되거나 작업이 다른 날로 이어져도 전수 검수 범위와 진행 상태를 잃지 않기 위한 영구 기록이다. 작업을 재개할 때 가장 먼저 이 문서와 `tmp/question-quality-audit.json`을 확인한다.

## 최종 목표

- 원문 범위: 2004-02-15부터 2026-08-02까지 교사용 PDF 91개
- 전체 출제 문항: 4,550개
- 고유 문항군: 2,037개
- 원문 이미지가 있는 문항: 350개
- 문제와 선택지는 축약·의역·재작성하지 않는다.
- 원문 이미지가 필요한 문항은 이미지가 항상 표시되어야 하며 실패 시 자동 재시도와 수동 재시도 수단을 제공한다.
- 모든 해설은 정답 근거, 네 선택지 각각의 고유한 O/X 근거, 핵심 개념을 초심자도 이해할 수 있게 설명한다.
- `문제에서 요구한 조건에 해당하지 않습니다`, `정답 선택지는 ...`, `핵심 정의·계층·규격과 대조` 같은 내용 없는 자동 문구를 최종 결과에 남기지 않는다.
- 연결 개념은 단순 열거하지 않고, 본문 개념과 어떤 관계인지 한 문장 이상 설명한다.

## 재개 절차

1. `git status --short`로 미완료 변경을 보존한다.
2. 이 문서의 첫 번째 `[진행 중]` 항목부터 이어간다.
3. `npm run audit:quality`를 실행해 최신 결함 수를 확인한다.
4. 완료한 묶음은 이 문서에 날짜·문항군 수·커밋을 기록한다.
